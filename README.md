# Simple Cashier & Analytics System

## 📌 Deskripsi
Sebuah program kasir berbasis Command Line Interface (CLI) yang terintegrasi dengan database SQLite. Program ini tidak hanya memproses pembayaran, tetapi juga mencatat riwayat transaksi secara otomatis dan menyajikan analisis data penjualan beserta prediksi stok sederhana. Project ini dibuat untuk memenuhi Final Capstone Project Bootcamp Python.

## ✨ Fitur
1. **Payment**: Proses pembayaran barang dan pengurangan stok otomatis di database.
2. **Manage Product**: Tambah, lihat, update, dan hapus data produk.
3. **File Processing**: Menyimpan riwayat transaksi ke dalam file `TransactionHistory.csv`.
4. **Analytics & Prediction**: 
   - Menghitung total pendapatan dan barang terlaris menggunakan **Pandas**.
   - Visualisasi data penjualan menggunakan **Matplotlib**.
   - Prediksi kebutuhan stok 7 hari ke depan menggunakan **NumPy**.

## 🛠️ Teknologi yang Digunakan
- **Python 3** (Bahasa Pemrograman Utama)
- **SQLite3** (Database Management)
- **Pandas** (Data Processing)
- **Matplotlib** (Data Visualization)
- **NumPy** (Basic Prediction)
- **CSV** (File Processing)
